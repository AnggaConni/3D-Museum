Open-source configuration tool

Museum JSON Editor

Configure your collection, title theme, 3D models and environment. Export a valid source.json without editing application code.

Safe by design: runs entirely in your browser. No backend, database, GitHub token, or sign-in is needed. Changes are not published automatically; export the file and replace source.json yourself.

01 · Collection source

Where the museum reads its collection data.

Google Sheets

Publish the chosen sheet/tab to the web as CSV. A normal sharing link is not the same as a published CSV link.

New to this? This editor changes website settings. To add or edit each catalogue item, open your Google Sheet. Use image_urls for several image links (separate links with |), or image_url_1, image_url_2, and so on.

Recommended for beginners: use plain text in the description cell. It is simpler and safer. HTML is optional only if you need bold text, tables, or links; supported HTML is filtered before display. Read the beginner guide.
Try the demo data: download a ready-made CSV with 18 example items, three image links per item, and long rich descriptions with tables. Import it into Google Sheets to test the carousel and formatted descriptions.

02 · Opening theme

Choose a title-screen look and customize its copy.

Built-in styles: egyptian_tomb, ich_crafting, neo_museum.

The style selects one of the built-in CSS designs. Text edits are stored in the selected preset in JSON.

03 · Category models

Change model paths, target sizes and enabled status.

The current scene has three category slots: underwater, ancient_craft, and museum. An extra model can be configured here, but a new category also needs a matching scene slot in index.html.

04 · 3D environment

Configure the surrounding GLB scene.

Position offset (X / Y / Z)

Width scales the environment proportionally. Position is applied after centering and ground alignment.

05 · Export configuration

Review the generated JSON, then download it as source.json.

No backend

Exporting does not change GitHub. After downloading, open your repository → source.json → Edit (pencil) → replace the contents → Commit changes.
